Tampermonkey/Greasemonkey userscript that marks links which run JavaScript instead of opening a page: they get an underline and an overline, so you can spot them without hovering.

Install: with Tampermonkey or Greasemonkey installed, open [the raw script](https://raw.githubusercontent.com/rluks/javascript_link_distinguisher/main/javascript_link_distinguisher.user.js).

More: [JavaScript Link Distinguisher (JLD)](https://romanluks.eu/blog/javascript-link-distinguisher-jld/)
